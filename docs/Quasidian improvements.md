# Improvements — Quasidian
#### Idees de millora per a una segona fase del desenvolupament de **Quasidian**
- En iniciar una línia amb "- ", el guió només s'ha de mostrar quan el cursor estigui tocant-lo; sinó s'ha de mostrar el bullet. I la línia d'abans no s'ha de mostrar com a heading 2 (només ho ha de fer amb 3 o més guions junts, no només amb un). El bullet ha de quedar més indentat (no a ran de text). També, cal aliniar tot el text d'una bullet list amb la primera lletra, no amb el guió. El mateix aplica a les numeracions.
- Tab $\to$ indentar llistes, o posar tab, però no canviar el focus a un altre control.
- Títol amb "nom de la carpeta - nom del fitxer" (no Quasidian).
- Icona pròpia (no de tauri).
- Icones de la barra (semblants a Obsidian).
- Integrar YAML (amb tags i aliases).
- Headings: espaiat més gran a sota i, sobretot, a sobre.
- Headings: lletra més grossa (fer captura d'Obsidian).
- Col·lapsar seccions.
- Línies (de taules i línies ---) més visibles, més brillants.
- Taules: facilitar-ne l'edició (moure, afegir i crear columnes i rows, alinear text, etc.).
- Text blanc, links liles.
- Selecció de text: fons lila.
- En seleccionar un text, permetre rodejar amb ==, (), $$, [] en comptes de substituir-lo.
- Posar vista de seccions al panell de la dreta. 
- Barra inferior: backlinks, paraules, caràcters, edició/lectura.
- Botó dret del mouse al nom de fitxer $\to$ menú contextual (fer captura d'Obsidian). 
- Botó dret del mouse al text $\to$ menú contextual (fer captura d'Obsidian).
- Settings: habilitar/deshabilitar auto-pair brackets i auto-pair Markdown syntax.
- Settings: una X per tancar la finestra de settings.
- Barra superior del text en edició (panell central) ok, però amb el nom del fitxer centrat.
- 3 barres superiors a cadascun dels 3 panells:
    -  esquerre (fitxers, buscar, obrir una altra carpeta/fitxer)
	-  central (col·lapsar panell esquerra, pestanyes de fitxers oberts, col·lapsar dret)
	-  dret (backlinks, outgoing links, outline)
- Botó "Obre un fitxer" $\to$ símbol amb tooltip per a obrir una altra carpeta (especificant o no un fitxer concret).
- Permetre dockar pestanyes en vistes dividides (particions del panell central).
- Permetre múltiples instàncies d'un mateix fitxer (que estigui obert en més d'una pestanya).
- Afegir footnotes.
- Afegir callouts.

#### Modes multicarpeta
- Mode CLAUDE: activació automàtica només si la carpeta en edició és una carpeta Claude (si conté un fitxer CLAUDE.md o una subcarpeta .claude), o si penja d'una carpeta Claude.
- Mode GPT: anàleg al mode CLAUDE, però per a GPT.
- Els modes multicarpeta han de funcionar com un vault d'Obsidian.
- El títol passa a ser "nom del vault - nom del fitxer" (no Quasidian).
