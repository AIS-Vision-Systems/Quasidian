# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities.

Instead, use one of these private channels:

- **GitHub private vulnerability reporting**: go to the repository's *Security* tab → *Report a vulnerability*.
- **Email**: <xavi@aisvision.com>

Include steps to reproduce, the affected version, and your OS. You will receive an acknowledgement as soon as possible, normally within a few days.

## Supported versions

Only the latest release receives security fixes.
